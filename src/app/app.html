Save a backup of your digital ID

Your digital ID is ready. Save a backup file before you use it. The file is the only way to:

  • use this ID on another computer or in another browser
  • get it back if this browser's data is ever cleared
  • sign with the same ID in Adobe Acrobat or other PDF apps

Anyone who has both the file and the password can sign as you. Keep them apart, for example the file in your cloud storage and the password in a password manager.

This is the only chance to save it. To protect your ID, it can't be copied out of the browser later.

To restore it later, choose Import a .p12 or .pfx file under Digital ID and enter the same password.

Import a digital ID

Choose a .p12 or .pfx file: an Ink Sign backup, or an ID from a certificate authority or another program.

This replaces the digital ID you have now. Make sure you have its backup if you'll need it again.
